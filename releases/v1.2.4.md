## The Hack Repair Guy's PHP Checker 1.2.4

### Highlights

- **Exclude `Internal.*` formatting sniffs:** [`THRG_PC_Engine::process()`](../includes/class-thrg-pc-engine.php) skips PHPCS `Internal.*` non-compatibility notices (such as `Internal.LineEndings.Mixed`) so mixed CRLF/LF endings no longer inflate warning counts.
- **Expanded legacy `function_exists()` + `else` & dead-variable guard detection:** [`THRG_PC_Context`](../includes/class-thrg-pc-context.php) now recognizes core built-in functions guaranteed on the target PHP version (e.g. `error_clear_last` in PHP 7.0+), automatically downgrading their unreachable `else` branches and `isset($var)` checks for variables only ever assigned in guarded branches.
- **Fatal vs. non-fatal error wording:** [`THRG_PC_Results::is_fatal_rule()`](../includes/class-thrg-pc-results.php) distinguishes hard fatal rules from non-fatal behavioral/INI removal rules (`RemovedIniDirectives`, `ArgumentFunctionsReportCurrentValue`) so component summaries and the top Readiness Verdict banner only warn of fatal crashes when hard-fatal rules are present.
- **Originating PHP version & `NeedsInspection` deprioritization:** [`THRG_PC_Results::rule_php_version()`](../includes/class-thrg-pc-results.php) extracts and displays the originating PHP version (e.g. `since PHP 7.0`, `since PHP 8.2`) in finding tables, and `NeedsInspection` warnings sort after actionable findings.
- **Broader bundled dependency detection:** [`THRG_PC_Results::file_origin()`](../includes/class-thrg-pc-results.php) now classifies `libraries/`, `library/`, `lib/`, `libs/`, `sdk/`, `sdks/`, `mailer/`, and `imap2/` consistently as `bundled dependency`.
