## The Hack Repair Guy's PHP Checker 1.2.0

### Highlights

- **Weekly or monthly scheduled rescans with update-problem email alerts:** [`THRG_PC_Schedule`](includes/class-thrg-pc-schedule.php) now supports both **Weekly** (default, with day-of-week selector) and **Monthly** (day 1–28) schedules, automatically rescanning against the next PHP version and pre-scanning pending updates so administrators receive an email alert whenever an update or the next PHP version has known compatibility problems.
- **"Fixed in a newer WordPress.org version" verification:** [`THRG_PC_Prescan::check_wporg_fix()`](includes/class-thrg-pc-prescan.php) and [`THRG_PHP_Checker::component_finding()`](includes/class-thrg-php-checker.php) check whether a plugin from WordPress.org that fails a scan has a newer release, stream-scan the newer package in memory against the target PHP version, and badge the plugin card (`Fixed in vX.Y on WordPress.org`, `Fatal errors fixed in vX.Y`, or `Still fails in vX.Y`) with a one-click **Check if fixed on WP.org** button.
- **Runtime PHP deprecation notice log, grouped by plugin:** [`THRG_PC_Runtime_Log`](includes/class-thrg-pc-runtime-log.php) adds an opt-in live `E_DEPRECATED` / `E_USER_DEPRECATED` collector (with backtrace attribution for WordPress `_deprecated_function()` calls) plus an on-demand `wp-content/debug.log` deprecation importer, displaying deduplicated notices, hit counts, and timestamps grouped by plugin or theme.
- **Companion tool recommendation:** Added a recommendation in **Support & Companion Tools** for pairing PHP Checker with our free **The Hack Repair Guy's Plugin Detective** plugin when testing plugins and PHP upgrades.
