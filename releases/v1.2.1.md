## The Hack Repair Guy's PHP Checker 1.2.1

- Bind an active scan to its job token and initiating administrator. Atomic claims and a step lock prevent overlapping requests from replacing scan state; a stale step cannot restore a stopped job.
- Attribute runtime deprecations correctly when PHP reports a canonical plugin path that differs from WordPress's symlinked plugin directory.
- Select the release asset whose filename exactly matches the tagged version, regardless of asset order.
- Remove tracked per-user email cooldown transients during uninstall.
