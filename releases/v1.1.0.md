# thrg-php-checker 1.1.0

- **Client-first report hierarchy:** Incompatible plugins and themes (`breaks`) now appear right at the top of Checks & Findings above the fold, followed by deprecation warnings, server PHP lifecycle status, and a collapsible table of compatible components.
- **Plain-English Readiness Verdict banner:** Added a top summary callout below the scan toolbar that immediately answers whether the site is ready for the target PHP version or which plugin blocks the upgrade.
- **Accurate summary counts:** Removed the redundant scan-coverage meta card once components are scanned (fixing double-counting in the red Summary Tile, Report History, and Email subject lines) and suppressed the Pending Update Compatibility card when Update Pre-Scan is disabled.
- **Streamlined cards & collapsible technical drawers:** Replaced repetitive boilerplate text on component cards with header origin badges (`in plugin code` vs. `in bundled library`), a highlighted **What to do** box, sorted `ERROR`-first tables, and collapsible `<details>` code drawers (collapsed by default so cards stay clean, capped at 8 initial rows when opened with an overflow drawer, plus an **Expand all code tables** button).
- **Grouped navigation & polish:** Reorganized the left sidebar into urgency groups (**Action Needed**, **Warnings & Review**, **Passed Checks**, **Tools & Settings**) with issue-count badges, expanded bundled library detection (`Pear`, `PHPMailer`, `TCPDF`, `Dompdf`, `mPDF`, `vendor-prefixed`), and fixed `[hidden]` button specificity and rule-code table wrapping.

No changes to stored option schemas; existing cached scan results and report history are preserved.
