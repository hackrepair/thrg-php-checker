## The Hack Repair Guy's PHP Checker 1.2.6

### Highlights

- **Notices no longer land inside the header:** WordPress moves admin notices to just after the first `h1` on a page unless the page has a `wp-header-end` marker. PHP Checker's `h1` sits inside the branded header, so notices from other plugins (and PHP Checker's own confirmations) appeared in the middle of it. `includes/view-header.php` now prints `<hr class="wp-header-end" />` right after the header, so notices appear below it, above the scan form.
- **Other plugins' notices tucked away on this screen:** the PHP Checker screen now hides notices from other plugins and WordPress and shows a small bar ("3 notices from other plugins or WordPress are hidden on this page. Show"). One click shows them again, below the header. PHP Checker's own messages (report emailed, history cleared, settings saved) always stay visible. It is CSS and a small script on this screen only: nothing is removed from WordPress, and without JavaScript the notices stay visible.

### Release plan

1.2.6 is a **post-approval** release. 1.2.5 is in WordPress.org review; 1.2.6 is not to be uploaded or committed to SVN until the plugin is accepted.
